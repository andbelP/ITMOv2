# Отчет по Практике 4: Настройка агентной среды, Skill и кастомного MCP

Этот отчет описывает результаты выполнения Практики 4 по курсу «Инструменты AI-инжиниринга» для проекта **AlgoPlace**.

---

## 1. Настроенная среда агента

В репозитории практики были созданы и настроены следующие файлы среды:
- **`AGENTS.md`**: Свод инструкций, архитектурных гайдлайнов и соглашений по коду для проекта **AlgoPlace** (Go Backend + React Frontend).
- **`opencode.json`**: Конфигурационный файл среды OpenCode, определяющий провайдера моделей VseLLM (использующего `google/gemini-3.8-flash`) и подключающий кастомный MCP сервер `algoplace-helper`.
- **`runner.sh`**: Скрипт автоматического запуска верификации (тестов), который обращается в репозиторий `AlgoPlace` и выполняет команду `./scripts/verify-tests.sh` для автоматического контроля регрессий.

### Обоснование выбранных подключений
1. **Runner/Hook (`verify-tests.sh` / `runner.sh`)**: Необходим для того, чтобы агент запускал компиляцию TypeScript/Vite и тесты Go перед завершением работы, минимизируя вероятность попадания ошибок в коммиты.
2. **Custom MCP (`algoplace-helper`)**: Связывает базу знаний о сложности алгоритмов со средой агента, предоставляя точную информацию по асимптотической сложности задач (Time & Space complexity) прямо в контекст генерации кода.

---

## 2. Разбор и применение готового Skill

Для работы с фронтенд-частью AlgoPlace был интегрирован готовый skill **`vercel-react-best-practices`**:
- **Устройство**: Данный skill содержит набор из 70 структурированных правил оптимизации производительности для React и Next.js. Все правила распределены по 8 категориям приоритетов (от критического устранения асинхронных водопадов `async-` до микрооптимизаций на уровне JavaScript `js-`). Каждое правило представляет собой отдельный Markdown-файл с плохими и хорошими паттернами кодинга.
- **Польза и запуск**: При редактировании или создании компонентов интерфейса AlgoPlace (например, панели решения задач или редактора кода Monaco Editor) агент автоматически загружает этот skill. Это предотвращает повторные лишние ререндеры, оптимизирует динамический импорт тяжелых библиотек и обеспечивает высокую плавность UI-интерфейса платформы.

## 3. Собственный MCP-сервер

Мы реализовали кастомный облегченный MCP-сервер **`algoplace-helper`** на Python (расположен в `practices/practice_04/mcp-server/server.py`).

### Описание инструмента
- **Имя**: `get_problem_complexity`
- **Описание**: Возвращает точную временную (Time) и пространственную (Space) сложность алгоритма по его slug-имени для платформы AlgoPlace.
- **Входные параметры**: `slug` (строка, обязательный).

### Результаты тестирования вызовов

#### Успешный вызов (`slug: "two-sum"`):
```json
// Запрос (tools/call)
{"id": 3, "method": "tools/call", "params": {"name": "get_problem_complexity", "arguments": {"slug": "two-sum"}}}

// Ответ сервера
{
  "jsonrpc": "2.0",
  "id": 3,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "Алгоритм: two-sum\n- Временная сложность (Time Complexity): O(N)\n- Пространственная сложность (Space Complexity): O(N)\n- Описание: Использование Hash Map для быстрого поиска дополнения числа."
      }
    ],
    "isError": false
  }
}
```

#### Обработка ошибочного входа (неизвестный `slug`):
```json
// Запрос (tools/call)
{"id": 4, "method": "tools/call", "params": {"name": "get_problem_complexity", "arguments": {"slug": "unknown-algorithm"}}}

// Ответ сервера
{
  "jsonrpc": "2.0",
  "id": 4,
  "result": {
    "content": [
      {
        "type": "text",
        "text": "Ошибка: Алгоритм с именем 'unknown-algorithm' не найден в базе знаний AlgoPlace Complexity Helper."
      }
    ],
    "isError": true
  }
}
```

#### Обработка ошибок валидации (отсутствует обязательный параметр):
```json
// Запрос (tools/call)
{"id": 5, "method": "tools/call", "params": {"name": "get_problem_complexity", "arguments": {}}}

// Ответ сервера
{
  "jsonrpc": "2.0",
  "id": 5,
  "error": {
    "code": -32602,
    "message": "Ошибка: Обязательный параметр 'slug' отсутствует или пуст."
  }
}
```
