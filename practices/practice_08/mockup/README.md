# AlgoPlace — UI Mockup (Практика 8)

## Инструмент
Интерактивный макет создан с помощью AI-ассистента (Antigravity / Claude) на основе дизайн-системы **shadcn/ui**.

## Как открыть
```bash
# Просто откройте в браузере:
xdg-open docs/mockup/index.html
# или
firefox docs/mockup/index.html
```

## Пользовательский сценарий
**Пользователь заходит на AlgoPlace → выбирает задачу → пишет решение → нажимает Submit → видит результат.**

## Состояния интерфейса (переключаются кнопками вверху макета)

| # | Состояние | Описание |
|---|-----------|----------|
| ① | **Initial** | Пользователь видит условие задачи, примеры, ограничения. Справа — редактор кода с шаблоном. Внизу — вкладка Testcase с входными данными. |
| ② | **Loading** | Пользователь нажал Submit. Кнопки Run и Submit заблокированы (`disabled`). Текст кнопки: «Evaluating…». Спиннер с сообщением «Compiling and judging…». |
| ③ | **Accepted (Success)** | Вердикт «Accepted» с зелёным бейджем. Метрики (Runtime, Memory). Модальное окно «Task Solved!» с кнопками «All Problems» и «Next Task». |
| ④ | **Error (Wrong Answer)** | Вердикт «Wrong Answer» с красным бейджем. Алерт с описанием ошибки и кнопкой «Retry Submission». Детализация по тест-кейсам: какой прошёл, какой нет. |
| ⑤ | **Empty Data** | Пользователь ещё не запускал код. Пустое состояние с подсказкой. |

## Компоненты shadcn/ui, использованные в макете

- **Button** — кнопки Run, Submit, Reset, Retry (варианты: default, primary, disabled)
- **Badge** — бейдж сложности (Easy/Medium/Hard) и статус-бейджи (Accepted, Wrong Answer)
- **Card** — карточки примеров, тест-кейсов, результатов
- **Tabs** — вкладки Description / Submissions и Testcase / Test Result
- **Dialog (Modal)** — модальное окно «Task Solved!» при успешной отправке
- **Select** — выбор языка программирования (C++ / Python / JavaScript)
- **Alert** — сообщение об ошибке с кнопкой повтора

## Единая тема (Design Tokens)

| Токен | Значение | Назначение |
|-------|----------|------------|
| `--bg-base` | `#0a0a0b` | Основной фон |
| `--bg-card` | `#111113` | Фон карточек и панелей |
| `--border` | `#27272a` | Бордеры |
| `--ring` | `#6366f1` | Focus ring (a11y) |
| `--emerald-500` | `#10b981` | Акцент: успех, кнопка Submit |
| `--rose-400` | `#fb7185` | Ошибки |
| `--radius` | `0.5rem` | Скругление (shadcn default) |

## Доступность (a11y)
- Все интерактивные элементы имеют `aria-label`
- Видимый focus ring через `:focus-visible` (box-shadow с `--ring`)
- Кнопки становятся `disabled` при ожидании ответа (защита от double-submit)
- Контрастность текста соответствует WCAG AA

- **AI предложил:** общую структуру макета (split-layout: условие слева, редактор справа), выбор компонентов shadcn/ui, цветовую палитру, все 5 состояний, стилизацию кода в редакторе.
- **Ручные корректировки:** промпт уточнялся на основе реальных типов данных проекта (`Problem`, `SubmissionResult`), добавлены конкретные примеры задач из AlgoPlace, скорректирован текст ошибок.
